Projects can created and should be maintained only within context of this free-orgx app.

Tasks and Projects are entities that contain a chat. The chat is assided by an ai assistant.
The Ai assistant is constantly trying to document, what the users/develops and the project owner write in the chat. The ai assistant has 2 funcs. Smooth out the written chat to documentation. And serve the info in a fuzzy was, so if someone asks about the project without any knowledge the ai finds the relevant parts of the chat, descriptions etc. 

Nothing is ever set in stone. The Tasks can change, tasks have a description, and priority. 

Project settings allow to automatically assing users/devs to new tasks, based on how much tasks they are currently working on, and the priority the tasks have.
